Smart DVI

The app

Smart DVI is a vehicle inspection app for the Meta Quest 3, and auto shops use it in production. The technician wears the headset while working through the shop’s inspection checklist. They grade each item, take photos by looking at the part, and record notes by voice. The finished inspection goes to the service advisor as a repair order, and the customer approves or declines it line by line.

I’m the lead engineer. I run the app’s development, and I own its AI, which covers photo grading, the agents on the headset, VIN reading and speech.

What the AI does

The readings run as agents on the headset. An agent runs when the technician takes a photo, records a note or connects to the car. Shops turn agents on per checklist item and choose whether each one fills in the answer or only suggests it. An agent never changes a value the technician entered, and it only suggests a reading it isn’t confident about.

VIN reading takes a burst of frames and keeps the sharpest. It tries the barcode first. If that fails, a vision model reads the characters and marks the ones it isn’t sure of, and the VIN’s check digit is used to correct them.

How I test changes

Before I change how photos are graded, I build a test set from photos technicians have already graded and run the candidate models and prompts against it. The backend switches to whichever scores best. Technicians confirm every grade, because the same tests showed the model’s confidence score doesn’t predict when it’s wrong.

I also write the specs the backend and web teams build from, and I spend time in shops watching technicians use the app.
